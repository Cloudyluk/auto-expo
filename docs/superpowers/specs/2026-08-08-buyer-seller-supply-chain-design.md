# 买卖双方导向的供应链展会库设计

## 背景与目标

现有库已覆盖 608 条展会和 36 个主题分类，但其主要价值仍是“找展会”。本次升级把产品重心转为买卖双方的参展决策：

- 买方：采购、供应链和工程团队能快速找到可开发供应商、替代方案、设备和材料的展会。
- 卖方：零部件、材料、设备和服务商能判断哪些展会适合找 OEM、Tier1、进口商、经销商或区域代理。

成功标准：用户从首页进入对应路径后，最多经过三次筛选即可获得按目标市场和客户类型排序的候选展会列表，并能看懂“为什么值得去”。

## 方案选择

采用“买卖双方双入口”，以供应链地图作为底层分类：

1. 首页增加 `采购找供应商` 和 `外贸找客户/渠道` 两个任务入口。
2. 每条展会补齐买方价值、卖方价值、客户类型、市场机会和行动建议。
3. 保留现有 36 个主题分类，并统一映射到供应链一级环节和二级子行业。
4. 以主记录加多标签治理重复展会，不允许同一展会因不同主题重复占用核心列表。

不采用纯榜单模式，因为单一星级无法解释一个展会对不同买卖任务的价值。

## 信息架构

```text
首页
├── 采购找供应商
│   ├── 找什么：材料 / 零部件 / 三电 / 芯片 / 制造装备 / 服务
│   ├── 去哪里：目标区域
│   └── 得到：采购优先展会与供应商类型
├── 外贸找客户/渠道
│   ├── 卖什么：产品所属供应链子行业
│   ├── 找谁：OEM / Tier1 / 进口商 / 经销商 / 售后渠道
│   └── 去哪里：目标区域
└── 全部展会
    ├── 主题分类
    ├── 供应链环节
    ├── 市场区域
    └── 2027预告
```

## 数据模型扩展

保留既有字段并新增以下标准字段：

```js
{
  tags: ["动力电池", "回收", "北美"],
  buyerValue: ["找电池材料", "找Pack设备", "寻找回收商"],
  sellerValue: ["对接电池厂", "接触OEM采购", "开发北美渠道"],
  buyerTasks: ["供应商开发", "技术选型", "替代方案"],
  sellerTargets: ["OEM", "Tier1", "进口商", "经销商", "维修渠道"],
  marketUse: "北美适合汽车零部件、智能化技术和售后渠道开发",
  action: "建议参观",
  confidence: "official"
}
```

字段规则：

- 重点展会必须提供 `buyerValue`、`sellerValue`、`sellerTargets`、`source`、`address`。
- 未能核实的日期、地址或展会状态必须保留为待复核，不做猜测。
- `confidence` 使用 `official`、`association`、`secondary`、`review` 四级标注。

| 一级环节 | 二级子行业示例 |

| 零部件 | 底盘、制动、转向、热管理、内外饰、座椅、照明、线束、连接器 |

## 页面与交互

### 采购找供应商

- 筛选：供应链环节、子行业、区域、采购任务。
- 卡片优先显示：可找供应商类型、典型供给能力、重点买家价值、日期地点和来源。
- 结果排序：采购价值、数据可信度、区域匹配度、星级。

### 外贸找客户/渠道

- 筛选：产品子行业、目标市场、客户类型、出海目标。
- 卡片优先显示：可遇见的客户类型、市场用途、渠道机会、日期地点和来源。
- 结果排序：外贸价值、目标客户匹配度、区域匹配度、数据可信度。

### 展会详情（第二阶段）

- 展会定位、买方价值、卖方价值、典型客户、行动建议、来源与更新时间。
- 展商/买家画像与往届规模，只有有官方或可信来源时才展示。

## 数据治理与去重

1. 以“主办方 + 官方名称 + 年份 + 城市 + 首日日期”作为主记录识别键。
2. 同一展会出现多个主题时合并为一个主记录，使用 `tags` 表示多标签。
3. 主题相近但不同城市或不同日期的巡展保留独立记录，并在未来用“系列展会”关联。
4. 旧记录信息更少时，合并到信息更完整、带官方来源的记录。
5. 每次批量更新后，运行重复、缺日期、缺场馆、缺来源和地域归类检查。

## 实施顺序

1. 数据清洗：持久化供应链标签，建立买卖双方字段，识别重复主记录。
2. 网站功能：增加双入口、任务筛选、排序与卡片指引。
3. 数据补齐：围绕重点子行业补官方展会，优先北美、欧洲、东南亚。
4. 详情与对比：加入展会详情、行动建议与年度行程规划。

## 验证方式

- 数据检查：每条重点展会具备日期、场馆、来源、买方/卖方指引。
- 任务检查：采购和外贸两条路径均能正确筛选、排序和清空条件。
- 回归检查：月度、国内、海外、推荐和 2027 预告统计不受影响。
- 人工检查：桌面与移动端不出现溢出、遮挡或筛选状态错误。
