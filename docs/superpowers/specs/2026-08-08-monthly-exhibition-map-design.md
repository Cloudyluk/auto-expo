# 月度全球展会地图设计

## 目标

在“月度时间线”中加入互动世界地图。用户切换月份后，地图自动高亮当月有展会的国家，并在举办城市显示展会数量；点击国家或城市后，优先展示该月对应的全部展会列表。

## 方案

采用内置 SVG 世界地图与本地城市坐标表，不使用地图账号、地图瓦片服务或后端接口。该方案能在 GitHub Pages 的纯静态环境中稳定运行。

## 页面结构

```text
月度时间线
├── 月份切换条
├── 全球展会地图
│   ├── 国家高亮层
│   ├── 城市数量点
│   └── 提示信息
├── 地图选中地区的当月全部展会列表
└── 原有月度展会列表
```

地图默认显示当月全球分布。点击国家或城市后，新增“地图选中地区”列表；用户点击清除按钮后恢复默认月度列表。中国以城市点呈现，与海外展会使用同一套交互。

## 数据与定位规则

新增独立地理数据模块，提供：

```js
getExhibitionGeo(event) => {
  country: '德国',
  city: '慕尼黑',
  latitude: 48.1351,
  longitude: 11.582,
  precision: 'city' | 'country'
}
```

- 优先从 `location` 识别已维护的城市并映射到城市坐标。
- 无法识别城市时，使用国家中心点并标记 `precision: 'country'`。
- 无法识别国家时，不在地图绘制，仍保留在月度列表中。
- 仅渲染 2026 主数据；2027 预告继续只在独立预告页显示。
- 同一城市的多场展会聚合为一个数量点，点击后显示全部记录。

## 视觉与交互规则

- 深色和浅色主题均可读；高亮颜色沿用现有蓝绿重点色。
- 国家有展会时使用低对比填充，城市点用更高对比的实心圆和数量标签。
- 点大小有最小与最大限制，避免数量变化导致版面跳动。
- 悬停显示国家、城市和展会数量；移动端使用点击显示。
- 城市点使用可访问的按钮语义，并提供文字列表作为地图的等价入口。
- 不使用外部在线地图底图，以避免跨域、加载和服务条款风险。

## 验收标准

1. 切换月份后，地图点和高亮国家与当月 2026 展会数据一致。
2. 点击城市数量点后，显示该城市该月全部展会。
3. 点击国家区域后，显示该国家该月全部展会。
4. 2027 预告不进入月度地图和 2026 指标。
5. 无坐标记录不导致页面报错或统计缺失。
6. 桌面与移动端地图、提示和列表不重叠、不溢出。

## 实施顺序

1. 创建地理映射和月度聚合函数，并以审计脚本验证识别覆盖率。
2. 在月度页面添加 SVG 地图、城市点和无障碍文字列表。
3. 将地图点击状态接入现有月度列表与月份切换。
4. 进行桌面/移动端交互和视觉回归检查。
