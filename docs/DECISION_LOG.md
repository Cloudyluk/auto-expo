# 项目决策日志

## 2026-08-08：保持纯静态架构

当前阶段继续使用单文件静态页面，优先完成数据可信度和供应链标签。原因是 GitHub Pages 部署简单、发布成本低，适合先验证展会库的使用方式。

## 2026-08-08：2026 与 2027 分开统计

2027 记录使用 `year` 和 `status: "2027预告"`，单独进入预告页，不混入 2026 月度、国内、海外和推荐统计，避免年度数据失真。

## 2026-08-08：主题分类与供应链分类并行

`cat` 保留用户熟悉的展会主题，`sc` 和 `vertical` 提供供应链视角。这样既能按“汽车电子元器件”找展会，也能按“线束/连接器/电子元件”或“电子电气/车规芯片”找供应商机会。

## 2026-08-08：官方来源优先

日期、地址、场馆和 2027 预告必须优先采用展会官网或主办方官方页面。只有发现线索但无法核实时，才保留“待复核”状态。

## 2026-08-08：先做可维护性，再做大规模视觉改版

下一步优先拆分数据、建立校验脚本和详情面板。视觉改版暂不作为主线，避免在数据仍频繁变化时增加维护成本。
