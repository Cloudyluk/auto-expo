# 汽车展会库供应链升级规划

## 当前修复目标

本轮先把现有站点从“展会日历”向“供应链决策库”推进一小步：

- 修复中国境内展会误归为海外的问题。
- 补充缺失或旧信息的重点海外展会。
- 在卡片上增加供应链阶段和区域标签。
- 为后续加入评分、官网来源、展商名录和参展决策提供字段入口。

## 目标用户

- 汽配外贸负责人：找海外渠道、代理、进口商和区域市场入口。
- 供应链/采购开发：找材料、零部件、设备、工艺和备选供应商。
- 技术/工程团队：找测试验证、智能驾驶、电动化、软件和法规技术活动。
- 企业管理层：判断年度参展、参观、招商和市场拓展优先级。

## 供应链分类

建议使用两套分类并行：

- 展会主题：汽配/汽保、新能源/EV、智能驾驶、测试验证、材料、模具、润滑油等。
- 供应链阶段：原材料、零部件、三电、电子电气、智能化、制造装备、售后流通、供应链服务、整车/OEM。

这样同一个展会可以既属于“汽配/汽保”，又属于“售后流通/渠道开发”，便于采购、外贸、工程团队按自己的任务筛选。

## 推荐评分

当前星级可保留，但建议改为透明评分：

- 采购价值：是否适合找供应商、替代料、设备或工艺。
- 外贸价值：是否适合中国供应商出海、找代理和经销商。
- 技术价值：是否有OEM/Tier1、法规、标准、工程论坛。
- 买家质量：是否有专业买家、主机厂、一级供应商、渠道商。
- 区域价值：是否覆盖目标市场，如北美、欧洲、中东、东南亚。
- 数据可信度：是否有官网、展商名录、往届报告和更新时间。

综合推荐指数可以由这些字段计算，而不是只靠手工星级。

## 关键功能路线

### 阶段一：数据可信度

- 增加官网、展商名录、报名链接、数据来源和更新时间。
- 给待定日期、已取消、延期、待复核展会加状态。
- 建立去重规则：一个主展会记录可以挂多个类别标签，避免同一展会重复占列表。

### 阶段二：供应链决策层

- 增加“适合谁去”：采购、外贸、技术、品牌、渠道、管理层。
- 增加“去展目标”：找供应商、找客户、看趋势、找设备、法规学习、竞品调研。
- 增加市场标签：北美、欧洲、东南亚、印度、拉美、中东/非洲、日韩。

### 阶段三：筛选和对比

- 新增供应链阶段筛选。
- 新增区域市场筛选。
- 新增“外贸优先”“采购优先”“技术优先”视图。
- 支持收藏、参展清单和年度行程导出。

### 阶段四：展会详情页

每个重点展会建议有详情面板：

- 展会定位和推荐理由。
- 核心品类和供应链阶段。
- 往届规模、典型展商、典型买家。
- 适合参观、参展、观望或跳过。
- 官网、展商名录、报名入口和来源状态。

### 阶段五：维护机制

- 把数据从 `index.html` 拆到 `data/exhibitions.js` 或 JSON。
- 增加 Node 校验脚本，检查缺字段、重复项、日期格式、海外/国内归类。
- 每次更新前跑数据 QA，避免统计和分类再次漂移。
- README 记录数据来源和更新时间。
