# 数据字典与质量规则

## 字段字典

| 字段 | 必填 | 说明 | 示例 |
|---|---:|---|---|
| `name` | 是 | 官方名称，中文说明可放括号 | `The Battery Show Europe 2026` |
| `year` | 建议 | 展会年份 | `2026` |
| `month` | 是 | 展会开始月份 | `10` |
| `date` | 是 | 面向用户显示的日期 | `10月12-15日` |
| `sortDate` | 是 | 排序日期，格式 `YYYYMMDD` | `20261012` |
| `location` | 是 | 国家、城市和场馆简写 | `德国 斯图加特 Messe Stuttgart` |
| `address` | 重点展会必填 | 可导航的详细地址 | `Messepiazza 1, 70629 Stuttgart, Germany` |
| `cat` | 是 | 原有主题分类 | `新能源/EV` |
| `sc` | 是 | 供应链环节 | `三电/电池供应链` |
| `vertical` | 建议 | 供应链子行业 | `动力电池/电驱/充换电` |
| `focus` | 是 | 展会价值和核心品类 | `电池材料、Pack、测试` |
| `audience` | 建议 | 适合去的人 | `采购、技术、外贸团队` |
| `market` | 是 | `中国` 或 `海外` | `海外` |
| `region` | 建议 | 欧洲、北美、日韩等 | `欧洲` |
| `star` | 是 | 0-3 级推荐 | `2` |
| `status` | 条件 | 预告、待复核、延期、取消 | `2027预告` |
| `source` | 重点展会必填 | 官方来源网址 | `https://...` |

## 供应链七大环节

| 一级环节 | 典型二级子行业 |
|---|---|
| 原材料 | 钢铝镁、工程塑料、橡胶、复合材料、电子化学品、稀土磁材 |
| 零部件 | 底盘、制动、转向、热管理、座椅、内外饰、线束、连接器、灯具 |
| 三电 | 动力电池、电驱、电机、电控、BMS、功率半导体、充换电、氢能 |
| 智能化 | 芯片、传感器、域控、ADAS、软件、数据安全、测试验证 |
| 制造装备 | 冲压、焊装、涂装、压铸、注塑、检测、机器人、工业软件 |
| 售后流通 | 汽配、汽保、轮胎、维修、润滑油、改装、再制造、拆车件 |
| 物流与服务 | 整车物流、零部件物流、包装、仓储、供应链软件、关务、合规 |

## 质量检查清单

- [ ] 名称、日期、城市、场馆四项不为空。
- [ ] 重点展会有详细 `address` 和 `source`。
- [ ] `sortDate` 与 `date` 的月份一致。
- [ ] `year: 2027` 的记录有 `status: "2027预告"`。
- [ ] 中国城市没有被归为海外。
- [ ] 没有同名、同日期、同场馆的重复记录。
- [ ] `cat`、`sc`、`vertical` 与展会实际内容一致。
- [ ] 来源链接仍可访问，且确实指向该展会。
