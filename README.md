## 功能特性

- 🏠 **总览** - 核心指标 + 旗舰展会精选
- 📅 **月度时间线** - 12个月展会日历浏览
- 🏷️ **分类导航** - 36个细分领域标签切换
- 🇨🇳 **国内展会** - 中国境内展会汇总
- 🌍 **海外展会** - 按大区分组的国际展会
- ⭐ **重点推荐** - 高优展会分级展示
- 🔍 **全局搜索** - 关键词实时检索
- 🌙 **主题切换** - 暗色/亮色双主题
